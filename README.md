# BookReader (v5.1.5)

完全ローカル完結・プライバシー重視の電子書籍リーダーです。  
小説（EPUB）とコミック（EPUB / ZIP / CBZ / RAR / CBR）の両方に対応し、書籍データ・読書記録・暗号化キーを外部サーバーへ一切送信せず、お使いの端末内だけで快適に読書と本棚管理ができます。

---

## 主な機能

### 1. 対応フォーマットと自動変換
- **EPUB（小説・コミック）**: 縦書き／横書き・ルビ・目次・画像ページに対応。
- **画像書庫（ZIP / CBZ / RAR / CBR）**: 画像のみの書庫を自動で右開きコミック用 EPUB に変換して取り込みます。
- **書庫内EPUB・入れ子書庫**: ZIP 内の複数 EPUB や、書庫の中に含まれる別の書庫も自動で展開・整理します。
- **ファイル中身ベースの形式判定**: 拡張子だけでなくファイル先頭のマジックバイトを見て ZIP / RAR を自動判別します。
- **停滞スキップ保護**: 展開が 5 秒間まったく進まないファイル／画像を自動でスキップし、手動の「スキップ」ボタンにも対応しています。
  - ※ パスワード付き（ヘッダー暗号化）RAR など一部の特殊形式には非対応です。

### 2. 快適な読書ビューア
- **レイアウト**: 縦書き／横書き切替、見開き表示、余白・文字サイズ・行間調整、カスタムフォント読み込みに対応。
- **ページめくりアニメーション**: 「なし」「フェード」「カール」の 3 種類から選択可能。
- **読書サポート**: 目次（TOC）ジャンプ、しおり、ハイライト・メモ、本文検索、読書進捗バー。
- **辞書連携**: 選択したテキストの先頭 30 文字までを Weblio で調べる機能を搭載（※辞書機能を使用しない限り外部通信は一切発生しません）。

### 3. 本棚・フォルダ管理
- **ホーム & ライブラリ**: 「続きを読む」・次の巻の提案・最近の読書を表示するホーム画面と、全書籍を整理できるライブラリ画面を切り替え可能。
- **フォルダ & サブフォルダ**: フォルダ・子フォルダの作成・移動・名前変更に対応。フォルダ内の本とサブフォルダはタイトル・巻数の自然順で並びます。
- **自動シリーズ整理 & 検索**: シリーズごとの自動まとめや、タイトル・著者名での絞り込み検索、一括選択操作（移動・削除・非表示）に対応。
- **誤操作を防ぐメニュー**: 長押しメニューをコンパクトな 2 列表示にし、対象の本や隣の本に重なりにくい位置に表示します。削除メニューも「この本を削除」「フォルダだけ削除（本は未分類に戻す）」「フォルダと中の本をすべて削除」と明確に分かれています。

### 4. プライバシー保護・暗号化ロック
- **完全ローカル保存**: 書籍本体は IndexedDB、設定・統計・しおり・履歴は localStorage に保存されます。
- **AES-GCM 暗号化**: 非表示にした本・フォルダの書籍本体は **AES-GCM** で暗号化保存され、ロック解除時のみ復号して表示されます。
- **パスコードなしでの即時非表示**: 本やフォルダを隠す操作自体はパスコード入力なしで即座に実行でき、ロック中の非表示追加分も次回ロック解除時に自動で暗号化されます。
- **生体認証（指紋・顔認証）**: パスコードに加え、WebAuthn パスキー（PRF 拡張）や生体認証による暗号鍵の復号・ロック解除に対応。パスコード入力画面表示時の自動ポップアップにも対応しています。

### 5. デザイン・カスタマイズ・省電力
- **テーマ**: ライト / セピア / ダーク / OLED / 時間帯連動（6–18時ライト・18–21時セピア・21–6時ダーク）およびアクセントカラー変更に対応。
- **UIモード切替（現行 / 軽量）**:
  - **現行**: 紙の質感やガラス調の表現を含むフルデザイン。
  - **軽量**: レイアウトはそのままに、SVG 紙ノイズ・`backdrop-filter`・グラデーション・重い影を無効化して描画負荷を軽減します。
- **見出し書体**: 「明朝」と「ゴシック」を切り替え可能。
- **省バッテリー設計**: 読書中の不要なバックグラウンド定期処理や DOM 全体監視を抑えたイベント駆動設計です。

### 6. 読書記録・バックアップ
- **読書統計 & 目標**: 読書時間の自動計測（無操作時の一時停止時間設定あり）、日別／本別の履歴、目標達成通知に対応。
- **バックアップ & 復元**:
  - **軽量バックアップ（JSON）**: 設定・読書位置・しおり・メモ・統計のみを保存。
  - **完全バックアップ（ZIP）**: 書籍本体やカスタムフォントを含めて保存・復元可能。
